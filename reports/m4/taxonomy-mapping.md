# M4 taxonomy mapping

Generated by `openinspect taxonomy audit` from `artifacts/m4/audit.json` and `configs/taxonomy.yaml` (re-render with `openinspect taxonomy report`). Code: `6ba0c9e075f1`; taxonomy SHA-256 `b8a8357314d4`.

Original labels are never changed: every box keeps the label its source gave it, and the normalized label is added next to it (`artifacts/m4/taxonomy-map.parquet`). A mapping rests on the source's paper and documentation and on sampled boxes, not on the label's name; the definitions and the reasoning are in [docs/TAXONOMY.md](../../docs/TAXONOMY.md).

## Statuses

| status | meaning |
|---|---|
| EXACT | the source's definition says what the normalized class says |
| COMPATIBLE | the same concept, with a documented difference in scope or wording |
| AMBIGUOUS | a candidate relation exists but the evidence does not settle it: not merged |
| SOURCE_SPECIFIC | no counterpart in another source: kept as its own class |
| REJECTED | not a defect class (a placeholder): never used |

A normalized class is a **benchmark class** when every source reaches it with an EXACT or COMPATIBLE mapping: only those are compared across sources. Benchmark classes: `short`, `open`, `mouse_bite`, `spurious_copper`.
