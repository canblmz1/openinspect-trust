Five folds; *stratified* deals the items of each source to the folds in a seeded order, *group-aware* keeps every A1 constraint group in one fold. Logistic regression (multinomial, standardized features, L2) and a depth-three decision tree (Gini), both implemented in NumPy.

## The depth-three trees fitted on all items

`metadata`:

```
if width <= 263:
  -> dspcbsd-plus
else:
  if is_png <= 0.5:
    -> pcb-ind
  else:
    -> pcb-defect
```

`boxes+pixels`:

```
if std_r <= 0.086:
  if mean_r <= 0.4529:
```

## Reading

Source identity is close to trivially predictable. That does not invalidate the source-held-out regimes; it means B measures a large source and domain shift (image size and format, colour and box statistics all change with the source), not only a subtle generalization gap, and a B score must not be read as a leakage effect.
